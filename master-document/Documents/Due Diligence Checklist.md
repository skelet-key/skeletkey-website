# Assembler Due Diligence Checklist
## Site visit — contract assembly (we source frames)
## Updated: 2026-08-21

### 1. Incoming & kit handling
* [ ] Secure receiving for **sourced folding frames** (no requirement that they weld our chassis).
* [ ] Dropout / headset / fold-latch gauges available or space for ours.
* [ ] ESD area and pack handling for **~60 lb / 8.5 kWh** modules.

### 2. Line
* [ ] Station layout for hub motor, FarDriver, deck, slide-in pack.
* [ ] Hipot / insulation tester.
* [ ] FarDriver flash + serial logging.

### 3. EOL
* [ ] Roller or short dyno for QS205 class hubs.
* [ ] Spray booth for electrical seals (IP65).
* [ ] Crate / 50% SoC process.

### 4. Commercial
* [ ] Accepts **consigned kits**, no parts markup.
* [ ] Capacity path to **40 units/day**.
* [ ] No personal guarantees on the MMA.
