SkeletKey Master Document Package
=================================

This package is fully portable.

Contents
--------
1. SkeletKey_Master_Document_Index.pdf
   - The master index (dark theme, single continuous page)
   - Click any document name in the Table of Contents — it opens the
     matching file from the Documents/ folder next to this PDF
   - All 23 source documents are also embedded as PDF attachments
     (open the Attachments / Paperclip panel in your PDF reader)

2. Documents/ folder
   - Every source file listed in the Table of Contents, renamed to the
     exact Title Case names used in the PDF
   - You can open these files directly from the folder if preferred

How to use
----------
- Open the PDF from inside this package folder (not from a copy elsewhere).
- Click a document name in the index to open it from Documents/.
- Or use the paperclip / Attachments icon to extract embedded files.
- Or browse the Documents/ folder — filenames match the PDF exactly.

No external paths or missing files. Everything needed is inside this package.
